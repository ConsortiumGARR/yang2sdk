# RFC 8526: NETCONF Extensions for NMDA (Updates: RFC 6241, 7950)

## 1. Context & Architecture
*   **Goal**: Extend NETCONF ([RFC6241]) to support the Network Management Datastore Architecture (NMDA) ([RFC8342]).
*   **Discovery**: Servers MUST advertise `:yang-library:1.1` with `revision` & `content-id` in `<hello>`.
    *   `urn:ietf:params:netconf:capability:yang-library:1.1?revision=<date>&content-id=<content-id-value>`
    *   Replaces `:yang-library:1.0` and `/modules-state` with `/yang-library` ([RFC8525]).
*   **Requirements**: Server MUST support `<operational>` and implement `ietf-netconf-nmda` YANG module.

---

## 2. Protocol Operations

### 2.1. `<get-data>`
*   **Purpose**: Retrieve data from any NMDA datastore (identified via `ds:datastore-ref` identity).
*   **Parameters**:
    *   `datastore` (Mandatory): target datastore identity (e.g., `ds:running`, `ds:operational`).
    *   `filter-spec` (Choice): `subtree-filter` (`anydata`) OR `xpath-filter` (`yang:xpath1.0`).
    *   `config-filter` (Boolean, Optional): Filter by `config true` or `config false`.
    *   `origin-filters` (Choice, Optional; only valid if datastore derivation $\ge$ `ds:operational`):
        *   `origin-filter*`: Select nodes matching/derived from specified origins.
        *   `negated-origin-filter*`: Select nodes NOT matching/derived from specified origins.
    *   `max-depth` (Union `uint16` 1..65535 | `unbounded`): Restrict subtree retrieval depth. Default: `unbounded`.
    *   `with-origin` (Empty, Optional; only valid for `ds:operational`): Request "origin" metadata attributes.
    *   `with-defaults` (Enum, Optional): `trim` | `explicit` | `report-all` | `report-all-tagged`.
        *   Requires capability: `urn:ietf:params:netconf:capability:with-operational-defaults:1.0` for `<operational>`.

### 2.2. `<edit-data>`
*   **Purpose**: Edit writable datastores (replaces `<edit-config>` choice architecture with identity-based targeting).
*   **Parameters**:
    *   `datastore` (Mandatory): Target writable datastore.
    *   `default-operation` (Enum): `merge` (default) | `replace` | `none`.
    *   `edit-content` (Choice, Mandatory): `config` (`anydata`) OR `url` (`inet:uri`).
*   **Error Handling**: Equivalent to `rollback-on-error`. No `error-option` or `test-option` parameters.

### 2.3. Augmented Base Operations
*   `<lock>`, `<unlock>`: Augmented with target `datastore` (`ds:datastore-ref`). Only valid on writable datastores.
*   `<validate>`: Augmented with source `datastore` (`ds:datastore-ref`). Only valid on configuration datastores.
*   *Failure behavior*: Unsupported datastores yield `<rpc-error>` with `<error-tag>invalid-value</error-tag>`.

## 3. YANG Module: `ietf-netconf-nmda`
```yang
module ietf-netconf-nmda {
  yang-version 1.1;
  namespace "urn:ietf:params:xml:ns:yang:ietf-netconf-nmda";
  prefix ncds;

  import ietf-yang-types { prefix yang; }
  import ietf-inet-types { prefix inet; }
  import ietf-datastores { prefix ds; }
  import ietf-origin { prefix or; }
  import ietf-netconf { prefix nc; }
  import ietf-netconf-with-defaults { prefix ncwd; }

  revision 2019-01-07 { description "Initial revision."; }

  feature origin;
  feature with-defaults;

  rpc get-data {
    input {
      leaf datastore {
        type ds:datastore-ref;
        mandatory true;
      }
      choice filter-spec {
        anydata subtree-filter;
        leaf xpath-filter {
          if-feature "nc:xpath";
          type yang:xpath1.0;
        }
      }
      leaf config-filter { type boolean; }
      choice origin-filters {
        when 'derived-from-or-self(datastore, "ds:operational")';
        if-feature "origin";
        leaf-list origin-filter { type or:origin-ref; }
        leaf-list negated-origin-filter { type or:origin-ref; }
      }
      leaf max-depth {
        type union {
          type uint16 { range "1..65535"; }
          type enumeration { enum unbounded; }
        }
        default "unbounded";
      }
      leaf with-origin {
        when 'derived-from-or-self(../datastore, "ds:operational")';
        if-feature "origin";
        type empty;
      }
      uses ncwd:with-defaults-parameters { if-feature "with-defaults"; }
    }
    output {
      anydata data;
    }
  }

  rpc edit-data {
    input {
      leaf datastore {
        type ds:datastore-ref;
        mandatory true;
      }
      leaf default-operation {
        type enumeration {
          enum merge;
          enum replace;
          enum none;
        }
        default "merge";
      }
      choice edit-content {
        mandatory true;
        anydata config;
        leaf url {
          if-feature "nc:url";
          type inet:uri;
        }
      }
    }
  }

  augment "/nc:lock/nc:input/nc:target/nc:config-target" {
    leaf datastore { type ds:datastore-ref; }
  }
  augment "/nc:unlock/nc:input/nc:target/nc:config-target" {
    leaf datastore { type ds:datastore-ref; }
  }
  augment "/nc:validate/nc:input/nc:source/nc:config-source" {
    leaf datastore { type ds:datastore-ref; }
  }
}
```
